# 法语背单词 · TEF/TCF 词汇

一个纯前端的法语背单词闪卡工具，面向 TEF/TCF 考试词汇——两个考试考的是同一套 CEFR 分级的通用法语能力，词汇本身没有本质区别，差异主要在考试形式（TEF 单独设“词汇与句法”模块，TCF 则融合在阅读/听力题里）。

线上地址：https://tef-vocab.moussebottle.workers.dev/

## 特点

- 2900+ 词条，覆盖 TEF/TCF 基础到进阶（约 A2–C1）主题，支持**主题分类**和**词性分类**两套并行的浏览维度
- 每个词条含国际音标（IPA），支持点击朗读（浏览器内置语音合成，无需联网；会自动挑选设备上的法语语音，而不是依赖浏览器猜语言）
- 多义词标注了额外义项（如 un vol：盗窃 / 航班），部分词条带原创例句
- 三种使用模式：
  - **闪卡背词**：大卡片 + 三档评分（没记住 / 有点印象 / 记住了）驱动的间隔重复（SRS），支持乱序播放、只看待复习、今日学习包（到期复习词 + 最多 10 个新词）、只看薄弱词（自动从复习记录里筛出反复记不住的词，无需手动标记）
  - **练习**：选择题 / 听写 / 造句 / 变位 / 易混词 五种小测验
  - **列表浏览**：按难度、分类、关键词筛选，支持标记已掌握
- 学习进度（SRS 数据）保存在浏览器本地，支持导出/导入 JSON 备份；检测到本地存储写入失败（常见于隐私模式）时会显示提示，而不是静默丢进度
- 支持离线使用（Service Worker 缓存）和“添加到主屏幕”（PWA manifest + 图标），当作独立小应用来用
- 纯静态站点，无需构建，可直接部署到任意静态托管平台

## 文件结构

- `index.html` —— 整个应用（HTML/CSS/JS 都在这一个文件里，含全部词条数据）
- `sw.js` —— Service Worker，离线缓存用
- `manifest.json` —— PWA manifest（图标、启动方式等）
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` / `favicon.png` —— 应用图标（同一套设计的不同尺寸）

## 部署

这是一个零依赖的静态站点。可直接部署到：

- **Cloudflare Pages**：New Project → Connect to Git → 选择本仓库，构建命令留空，输出目录填 `/`
- **GitHub Pages**：仓库设置里开启 Pages，选择 `main` 分支根目录
- 或任何静态文件托管（Netlify、Vercel 等）——直接指向 `index.html`

线上版本目前部署在 Cloudflare（随 GitHub 推送自动更新）。

## 词义来源

词义主要依据《牛津法英词典》（Oxford French Dictionary）常见义项整理。发音（IPA）、释义与例句为工具整理/原创生成，备考时建议对照权威音频与词典核实。
