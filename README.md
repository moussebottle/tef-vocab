# 法语背单词 · TEF/TCF 词汇

一个纯前端、单文件的法语背单词闪卡工具，面向 TEF/TCF 考试词汇——两个考试考的是同一套 CEFR 分级的通用法语能力，词汇本身没有本质区别，差异主要在考试形式（TEF 单独设"词汇与句法"模块，TCF 则融合在阅读/听力题里）。

## 特点

- 2900+ 词条，覆盖 TEF/TCF 基础到进阶（约 A2–C1）主题，分 17 个大类 / 子分类浏览
- 每个词条含国际音标（IPA），支持设备可点击朗读（浏览器内置语音合成，无需联网）
- 多义词标注了额外义项（如 un vol：盗窃 / 航班）
- 闪卡背诵 + 列表浏览两种模式，支持按难度、分类、关键词筛选
- 学习进度（已掌握标记）保存在浏览器本地，并支持导出/导入 JSON 备份
- 纯静态单文件（`index.html`），无需构建，可直接部署到任意静态托管平台

## 部署

这是一个零依赖的静态站点，`index.html` 即完整页面。可直接部署到：

- **Cloudflare Pages**：在 Cloudflare 控制台 New Project → Connect to Git → 选择本仓库，构建命令留空，输出目录填 `/`
- **GitHub Pages**：仓库设置里开启 Pages，选择 `main` 分支根目录
- 或任何静态文件托管（Netlify、Vercel 等）——直接指向 `index.html`

## 词义来源

词义主要依据《牛津法英词典》（Oxford French Dictionary）常见义项整理。发音（IPA）与释义为工具整理生成，备考时建议对照权威音频与词典核实。
